# 網站登入頁截圖辨識

查核日期：2026-09-17（Asia/Taipei）

## 本機流程

- 使用既有 Tesseract worker 與取消佇列，不登入、不呼叫雲端 AI。
- 網址抽取採逐行品質，避免整體 OCR 低分拖累清楚的網址；不跨低信心缺口拼字。
- 疑似網址列須具 OCR 座標，位於圖片頂部 22% 或底部 18%，不接受電子郵件。
  最多兩個區域，各做放大及對比兩次英文重辨識。網址字詞與已提供的字元信心
  均須至少 80，兩次須各只有一個且完全相同的網域，否則維持未確認。
- 位置與重辨識一致只代表候選網址列，不證明實際連線，也不能保證 OCR 完全正確。
- 帶有可見路徑、查詢或省略號的網址，不降格成根網址自動掃描；應貼上完整網址。
- 電子發票候選可額外做一次本機平台標題區域辨識，補強中文白字與有色背景。
  區域有像素上限，所有重試都在既有單一 worker 內，沒有背景無限重試。

## 官方映射與規則

依據財政部來源：
https://www.mof.gov.tw/singlehtml/979b54e408fb499eae3c1d9efe978868?cntId=54767ac72c924e56bbeebf50cf6a7c2a

首批映射僅為 `www.einvoice.nat.gov.tw` 與 `einvoice.nat.gov.tw`，保存來源及查核日期。
沒有把私人發票工具或所有 gov.tw 都視為此平台，也不將官網身分當成郵件寄送授權。
查核日期採台灣時區，超過 366 天後停止使用過期映射升高風險。

高風險需同時具備：可靠的官方平台名稱、重辨識一致的非官方網址列、手機號碼與
驗證碼（密碼）及手機條碼欄位脈絡。單獨有密碼欄位、圖形驗證碼、英文 E-Invoice
Platform 或 .com 網域都不成立。明確防詐範例文字不套用此高風險結論。

符合官方網址仍為截圖證據不足，不直接給安全保證；真實網站需走既有網址檢測。
看不清楚時提示裁切或貼網址，不能猜字，更不能把「驗證碼（密碼）」當成簡訊 OTP。
網站截圖報告不顯示寄件人欄位，不輸出手機號碼、密碼或圖形驗證碼數值。
既有郵件強威脅不會被較弱的網站分析覆蓋。

## 實測與限制

使用者提供的電子發票截圖：舊流程整體信心 64，沒有網址、風險 unknown。
新增本機重辨識後可抽出候選網域，標題區域可靠讀出電子發票整合服務平台，
實際 UI 顯示高風險網站截圖報告。測試攔截全部 POST/API 及網址掃描，未開啟可疑網站。
沒有新增該網域黑名單，也未提交原圖或含個資的 OCR 紀錄到版本庫。

辨識不是瀏覽器網址驗證。截圖可能經加工、地址列位置可能不同，重辨識可能一致地讀錯；
使用者可更正辨識文字後重新評估，或直接貼上網址。網址與圖片不傳送至聊天模型。

測試包含正版入口、私人服務、假後綴、低信心與不同結果、上下方網址列、郵件排除、
到期映射、隱私欄位排除、主畫面與聊天手機/桌面 UI、取消及使用者更正。

## 遠通電收與底部網址列擴充

- 整頁未找到網址時，對直式手機圖片上下方工具列各做一次英文探索；有且僅有
  一個網域文字區塊時，再映回原圖座標，縮至文字區域做兩次辨識，結果及信心
  必須一致。最多六次額外網址 OCR；不能只因第一輪得到候選就採用。
- 單獨 `@` 圖示不再觸發郵件重辨識。工具列附近的信箱修復還需寄件／收件欄位標記。
- 局部區域用文字塊分段模式，整頁工作恢復自動分段，避免 worker 狀態污染下次上傳。
- 對已辨識網址且出現車號查詢脈絡者，最多補三個品牌／淡色欄位區域，依然採 80 分
  證據門檻。重試有限、共用單一 worker，可取消，不用雲端 AI。
- 高風險組合為遠通電收／eTag 身分脈絡、非官方網址列、車號及身分證／統一編號欄位。
  不需要密碼，但只有車號、只有標誌、未知品牌或不清楚網址皆不成立。
- 主站及已查證的 css、epksa、dealer 主機精確匹配。其他 fetc.net.tw、utaggo.com.tw
  子網域及相關服務保留 unknown，不自動稱為官方或安全，也不只因未列入主站判偽冒。
