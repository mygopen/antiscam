# 165 防詐手法提醒

更新日期：2026-09-15

## P1 範圍

本次加入五類人工核對的手法索引：釣魚連結、假買家騙賣家、假求職與金融帳戶、
假投資出金受阻、假冒檢警與公務機關。依 165 打詐儀錶板公開話術整理通用特徵
及自行撰寫提醒，不搬運完整案例、圖片、影音或個人資料。

來源：https://165dashboard.tw/fraud-method

各筆 `data/fraud-method-reviews.json` 保留明確的官方說明網址、索引核對日期、
審核者、啟用狀態、必要概念、同義詞及提醒。此日期不是官方文章發布或更新日期，
不以全站頁尾日期推定個別內容更新。編譯只輸出核准資料，排除審核者欄位。

## 本機流程

`本機 OCR → ArticleSearch.searchMethods → 165 防詐手法提醒`

- 與 MyGoPen 共用有界、八行視窗的文字比對，不共用來源信任範圍。
- 每類至少兩個獨立概念；釣魚、假投資、假檢警需三組特徵。
- OCR 信心低於 80、過遠段落、單一品牌或泛用關鍵字不觸發。
- 文字先移除可見網址及電子郵件，再比對話術，不拿網址內的關鍵詞當行為證據。
- 否定詞檢查限同一子句內的前文，排除「請勿寄送金融卡」等建議。
  「不得告知他人」則是完整的保密指令概念。此為有限語句規則，不保證理解所有否定語境。
- 宣導或引用範例可以得到中性參考資料，不會因參考資料提高風險。
- 每個概念只計一次，最多顯示兩筆；沒有風險規則加分，沒有跨來源重複加分。
- 索引核對超過 366 天、未到核對日期或停用的資料不顯示。未命中不代表安全。
- 模組或索引缺失時不顯示提醒，不影響 OCR 或網址檢測。

## 呈現與隱私

主畫面、文字修正及聊天圖片結果均顯示同一套索引結果，附相似特徵、建議、
來源連結及「不代表 165 已查證這則訊息」。MyGoPen 相關查核分開標示。
複製報告包含兩種來源及其限制。新圖片、裁切、修正、取消及 OCR 失敗不沿用舊推薦。

圖片、OCR 文字及手法結果不送到雲端模型或 165。聊天圖片結果保留 `localOnly`，
之後一般文字聊天的序列化也排除這些資料。既有非 AI 網址檢測保持獨立。
本次沒有新增登入、API、向量資料庫或 AI 呼叫；網址分數與 EmailRisk 判斷未更動。

## 維護與 P2 界線

P1 由編輯閱讀原始來源後更新 JSON、核對日期與審核者，再執行測試及發布。
若要撤除，將 `status` 設為 `withdrawn`。不能因來源是官方就略過詞組與誤判審核。
不明朗的原文變化應先停用，確認後再核准；目前不提供自動內容變更偵測。

尚未接入自動抓取。一般抓取工具曾收到 403，瀏覽器可閱讀，但目前未確認外部
API、抓取規範及再利用授權。P2 須先確認這些條件，再加入獨立同步器、限量請求、
內容指紋與待審核 PR；不繞過驗證、不採付費代理、不讓同步結果自動改變風險規則。
