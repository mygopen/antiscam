# 165 打詐儀錶板網域審核

核對日期：2026-09-15

## 官方依據

- 警政署 165 全民防騙網明列儀錶板連結：https://165.npa.gov.tw/?to=pc
- 刑事警察局公告亦列出該網域：
  https://www.cib.npa.gov.tw/ch/app/news/view?id=1887&module=news&serno=44df0dce-674d-4ee2-9349-8b188f9dadd2
- 已在瀏覽器讀取 https://165dashboard.tw/fraud-method 及個別手法說明，
  頁面為內政部警政署 165 打詐儀錶板。一般抓取工具曾回傳 403。

## 可重現原因

原本 whitelist.json 已收錄此站，但 risk-config.js 未收錄內建可信身分。
前端以非同步 fetch 載入外部白名單，失敗時使用空陣列。使用正式核心及合成服務回應，
在外部白名單為空、內容 blocked 時，165dashboard 被英數混合與高亂度規則視為
可拋棄網域，結果 high / 100；有白名單時則是 unknown / 0。
這證明存在誤判路徑，不代表已取得使用者該次查詢的完整線上紀錄。

## 修正範圍

將 165dashboard.tw 加入內建 trustedGovernmentServiceDomains，避免依賴外部
白名單的載入時序。僅將已讀取核對的精確主機 165dashboard.tw 加入人工內容基準；
不將 .tw 全部視為政府網站，也不將此網域假標為 .gov.tw。
根網域信任採點邊界比對；其他子網域不繼承主站的人工內容審核。

頁面阻擋或缺少內容時，若必要威脅檢查完成且沒有強威脅，允許低風險結果。
介面仍揭露本次抓取狀態與人工審核不代表即時取得完整內容。
安全瀏覽服務無法確認時保留 unknown；黑名單、官方警示、敏感資料外送表單、
釣魚證據或高風險轉址仍優先判定高風險。不增加公司統編或捏造登記資訊。

驗證：tests/scan-core.test.js 使用正式核心，涵蓋空白名單、阻擋頁、明確威脅、
相似網域與未審核子網域。此修正不更動 165 手法索引或圖片零雲端 AI 流程。
